# FujiFilm & Cinema Equipment Rental (CINEFY)

Modern Next.js 14 web application for camera equipment rental, 360m² production studio booking, and video production services in Da Nang, Vietnam.

## Tech Stack
- **Framework:** Next.js 14 (App Router)
- **Styling:** Tailwind CSS + Custom Cinematic Dark Theme
- **Language:** TypeScript
- **Internationalization:** Bilingual (English & Vietnamese)

## Development
```bash
pnpm dev
# or
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the application.
