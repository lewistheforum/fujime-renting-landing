# Project Instructions

Before making any UI, UX, visual, typography, layout, or component decision:

1. Read `PRODUCT.md`.
2. Follow its color tokens, typography hierarchy, visual direction, UI patterns, and anti-patterns.
3. Do not invent prices, inventory, client logos, testimonials, contact information, or external assets.
4. Use clearly labeled mock data where verified information is missing.
5. Preserve responsiveness, accessibility, and the existing Next.js + TypeScript + Tailwind setup.
